# CampusWheels Vehicle-Rental Desk

## Description

CampusWheels is a simple Python vehicle-rental program developed using
Object-Oriented Programming concepts.

The program includes:

- Vehicle
- Renter
- ElectricCar
- Motorbike

It demonstrates classes and objects, encapsulation, inheritance, and
polymorphism.

## Files

- `rental.py` - Contains all the classes.
- `main.py` - Demonstrates how the program works.
- `README.md` - Contains project information and instructions.
